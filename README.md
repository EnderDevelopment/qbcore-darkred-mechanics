# DarkRedMechanics

DarkRedMechanics is a FiveM resource designed for QBCore servers, offering a customizable mechanic shop with a dark red aesthetic. This resource allows players to modify their vehicles with various wheels, paint options, and performance upgrades, providing an immersive and engaging experience within the game.

## Install

1. Download the DarkRedMechanics resource from the GitHub repository.
2. Extract the downloaded file into your FiveM server's `resources` directory.
3. Ensure you have the `qb-core` framework installed and properly configured on your server.
4. Add `ensure DarkRedMechanics` to your server.cfg file to start the resource automatically with your server.

## Use

1. Start your FiveM server and ensure the DarkRedMechanics resource is loaded.
2. Connect to your server as a player.
3. Use the command `/customs` in the game chat to open the customization menu.
4. Navigate through the menu to select wheels, paint, or performance upgrades.
5. Choose the desired modifications and apply them to your vehicle.
